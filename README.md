# Intro to LaTeX

This repository contains the presentation materials for the Intro to LaTeX workshop conducted on 10/20/2026.

### Workshop Overview

The workshop shows how to format lab reports, project write-ups and resumes with LaTeX. Attendees worked in Overleaf through a set of activities: making a first document and title page, adding headings, placing images, formatting tables, and starting from templates such as Jake's Resume Template and the Springer Nature LaTeX template. Each activity has its answer on the next slide.

### Setup

Make a free [Overleaf](https://www.overleaf.com/) account. Nothing needs to be installed.
